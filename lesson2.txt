git remote	Liệt kê tên các remote (biệt hiệu) đang kết nối (ví dụ: origin).
git remote -v	Xem chi tiết tên biệt hiệu + đường dẫn URL tương ứng (cả chiều fetch - tải về và push - đẩy lên).
git remote add <tên> <URL> -> 	Gắn một đường dẫn URL mới vào một cái tên biệt hiệu (thường đặt tên là origin).
git remote set-url <tên> <URL>	-> Đổi/Cập nhật đường dẫn URL mới cho biệt hiệu đã có sẵn.
git remote remove <tên>	-> Xóa bỏ liên kết đến một server từ xa.
